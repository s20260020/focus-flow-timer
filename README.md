# Focus Flow — 集中タイマー

見やすい円形ゲージと、集中・小休憩・長い休憩モードを備えた日本語のタイマーです。HTML/CSS/JavaScriptだけで動作し、追加のライブラリやビルド作業は不要です。

## 機能
- 集中 / 小休憩 / 長い休憩モード
- 25・50・15・5分のクイック設定と、1〜180分の自由設定
- スタート、一時停止、リセット、次のモードへ
- 終了時の音（3種類から選択）
- 集中セッション数の保存
- 全画面表示、ライト / ダークテーマ
- キーボード操作：`Space` で開始・停止、`R` でリセット
- スマートフォン・PC対応、外部ライブラリ不要

## ローカルで使う
`index.html` をダブルクリックしてブラウザで開いてください。

## GitHub Pages で公開する手順
1. GitHub にログインして、右上の **＋ → New repository** を選びます。
2. リポジトリ名を `focus-flow-timer` などにし、公開するなら **Public** を選んで作成します。
3. リポジトリの **Add file → Upload files** を選び、このフォルダー内の `index.html` と `README.md` をアップロードします。
4. **Commit changes** を押します。
5. リポジトリの **Settings → Pages** を開きます。
6. **Build and deployment** の **Source** を `Deploy from a branch` にします。
7. **Branch** を `main`、フォルダーを `/(root)` にして **Save** を押します。
8. 数分待ち、同じ Pages 画面に表示される公開 URL を開きます。通常は `https://あなたのユーザー名.github.io/focus-flow-timer/` の形式です。

## メモ
- 音を鳴らすには、最初にページ上でボタンを押す必要があるブラウザがあります。
- タイマーを実行しているタブを閉じると、カウントダウンは継続しません。
- 集中回数は同じブラウザのローカルストレージに保存されます。
